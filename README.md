# 🔐 Password Strength Checker

## 📌 Project Overview

The Password Strength Checker is a simple web-based application
that checks the strength of a password based on different security
requirements.

The application classifies a password as **Weak, Medium, or Strong**
by checking its length, uppercase letters, numbers, and special symbols.

## 🎯 Objective

To develop a simple password strength checker that helps users
understand whether their password is weak, medium, or strong.

## ✨ Features

- Check password length
- Check for uppercase letters
- Check for numbers
- Check for special symbols
- Display Weak, Medium, or Strong password status
- Show/Hide password option
- Clear password option
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
